Характеристики электровелосипедов для карточек товаров WooCommerce.

== Description ==

Мини-плагин добавляет к товарам WooCommerce поля контракта темы «Велоток»:

* `_velotok_tagline` — короткий слоган, строка;
* `_velotok_range_km` — запас хода в километрах, целое число от 0 до 500;
* `_velotok_motor_w` — мощность мотора в ваттах, целое число от 0 до 3000;
* `_velotok_weight_kg` — вес в килограммах, число с точкой от 0 до 500;
* `_velotok_wheel` — размер колёс, строка;
* `_velotok_badge` — бейдж (например, «Хит»), строка.

Поля доступны в редакторе товара в блоке «Характеристики велосипеда», а также через REST API. Значения санитизируются, запись защищена nonce и проверкой прав на редактирование товара.

Плагин не изменяет ядро WordPress, WooCommerce или другие плагины. При деактивации и удалении данные товаров сохраняются.

== Тематический охват контента (clarify-a2fd2f66) ==

Плагин содержит mocked-контракт тематического охвата контента. Текущая итерация не публикует материалы, не регистрирует таксономии и не обращается к внешним источникам.

Контракт `velotok_core_content_coverage_contract()` фиксирует:

* `mocked => true` и ссылку на спеку `clarify-a2fd2f66`;
* гибридный способ определения тематики (автоматическая проверка по условиям плюс ручное подтверждение спорных материалов);
* три обязательные тематики: обзор моделей в зелёной энергетике, требования законодательства, новости о зелёной энергетике;
* для каждой тематики — группы условий `all_of` и критерии качества.

Функция `velotok_core_content_coverage_evaluate()` проверяет материал по заголовку, краткому описанию и тексту. Материал признаётся соответствующим тематике, только если в тексте найдено хотя бы по одному термину из каждой группы `all_of`. `velotok_core_content_coverage_is_compliant()` проверяет одну тематику по ключу или slug, а `velotok_core_content_coverage_has_full_coverage()` подтверждает наличие всех трёх тематик.

Контрактный тест:

```bash
php wp-content/plugins/velotok-core/tests/content-coverage-contract-test.php
```

или без PHP:

```bash
node wp-content/plugins/velotok-core/tests/content-coverage-contract.test.js
```

Тест падает, если заглушка удалена, не помечена `mocked: true` или теряет одну из трёх тематик.

== Installation ==

1. Убедитесь, что установлен и активирован WooCommerce.
2. Скопируйте каталог `velotok-core` в `wp-content/plugins/`.
3. Активируйте плагин «Велоток: поля товара» в разделе «Плагины».
4. Откройте любой товар и заполните блок «Характеристики велосипеда».

== Frequently Asked Questions ==

= Что будет, если WooCommerce не активен? =

Плагин не ломает сайт и показывает администратору уведомление о необходимости активировать WooCommerce.

= Удаляются ли характеристики при удалении плагина? =

Нет. Поля товаров считаются данными клиента и сохраняются.
