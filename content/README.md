# Демо-товары

`products.json` — источник данных для идемпотентного seed-скрипта `scripts/seed.php`.

## Формат

Каждый товар содержит:

* `name` — название;
* `slug` — латинский идентификатор, по нему seed находит существующий товар;
* `category` — одна из категорий `city`, `mountain`, `cargo`, `folding`;
* `price` — цена в рублях числом;
* `old_price` — старая цена числом или `null`, если скидки нет;
* `short_description` — краткое описание;
* `description` — полное описание;
* `tagline`, `range_km`, `motor_w`, `weight_kg`, `wheel`, `badge` — поля контракта темы;
* `image` — имя файла из `assets/` (например, `model-city-classic-1-web.jpg`).

`weight_kg` можно оставить `null`, если вес не указан в исходных данных.

## Запуск seed

Из корня WordPress, где доступен WP-CLI:

```bash
wp eval-file scripts/seed.php
```

Скрипт:

1. создаёт или обновляет категории `city`, `mountain`, `cargo`, `folding`;
2. создаёт или обновляет товары, находя их по `slug`;
3. загружает картинки из `assets/` в медиатеку, если их там ещё нет;
4. выставляет цену, категорию и мета-поля товара.

Повторный запуск не создаёт дубликаты. Чтобы изменить товар, отредактируйте `products.json` и запустите seed снова. Удаление плагина не удаляет характеристики товаров.
