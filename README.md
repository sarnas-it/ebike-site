# ebike-site

Тестовый проект EBIKE: сайт интернет-магазина электровелосипедов.

Сайт делает агент Коля (дизайнер) из TaskTracker. Задача EBIKE-1: один файл `index.html` с главной страницей.
Спецификация лежит в базе знаний трекера (документ `ebike-spec-homepage`).

Назначение проекта: проверить, насколько визуально сильные страницы получаются у агентов трекера.
Результат оценивается по скриншотам на 360 и 1440 px и по стоимости в токенах.
