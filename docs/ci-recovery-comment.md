## Восстановление результата проверок

GitHub не отдал итоговый результат по одному из обязательных check runs: на
коммите остался `in_progress`-дубликат, хотя джоба CI завершилась успешно.
Отложенный мерж ждал этот статус и не мог завершиться.

Recovery-workflow повторно прогнал полный набор проверок
(`php-lint`, `php-tests`, `php-plugin-tests`, `plugin-tests`) на актуальном
head PR, завершил зависшие дубликаты check runs и опубликовал итоговый статус
`ci/recover` на проверенном коммите. Проверки не отключались и не сужались.
Если все они зелёные, отложенный мерж выполняется автоматически.
